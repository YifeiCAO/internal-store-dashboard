\begin{abstract}
我们研究一个严格的 ``Transformer 主干加外挂海马'' 系统：causal window Transformer 作为 PFC，仅从动作与感觉历史推断 latent context；动作驱动的 neural EC 形成关系结构；episode-local differentiable fast weights 作为 HPC 保存内容，并在 episode 结束后丢弃。模型不读取 room/context 标签、绝对位置、place ID、当前目标、memory slot 或第二套 fast weights。2D hidden-context A-B-A re-entry 的冻结 8-seed return-conflict accuracy 为 $0.8201\pm0.0200$；本轮进一步用强长度 OOD 与 gauge-paired counterfactual 排除了时间、当前 observation、短 action window 与当前路径 shortcut。Frozen DINOv2 spatial target audit 显示 conflict content 可分，而 ambiguous current frame/cue 的 context probe 均为 0.500。最小 visual A-B-A 在三个训练 seed 上达到 $0.9975\pm0.0014$ return-conflict accuracy；PFC-only 为 $0.3338\pm0.0046$，fixed-context 为 $0.4993\pm0.0010$，wrong-history 将预测推向另一 context 的比例为 0.9936。该结果建立了 2D 到高维视觉的最小机制桥，但仍是看过 validation 的 development pilot，只有一个共享 conflict place，不能冒充 fresh sealed world-model 结果。generic RGB strict rollout 的 C3 仍只相对 PFC-only 改善 $3.10\%$ 且区间跨零；C6 caller held AUC 0.513 的负结果继续保留。
\end{abstract}

\section{冻结架构与无 Oracle 合同}

\subsection{PFC、EC 与 HPC 的分工}

Transformer 本身就是 PFC。时刻 $t$ 的因果输入为动作 $a_t$、滞后感觉 $o_{t-1}$ 与上一内部 retrieval；长度 32 的 causal window 形成短期历史状态。一个低维持续 state 从动作与历史中推断 latent context $c_t$。Neural EC 只从动作积分关系结构，经过 sparse neural place projection 得到 $p_t$。地址采用乘性绑定
\begin{equation}
k_t=\operatorname{norm}\{\operatorname{vec}(p_t c_t^\top)\},
\end{equation}
而不是把 room ID 拼进 query。

HPC 是 episode-local fast-weight matrix $M_t$。读取先于当前真值写入：
\begin{align}
r_t &= M_t q_t,\\
M_{t+1} &= M_t+\alpha_t
\frac{(v_t-M_tq_t)q_t^\top}{\lVert q_t\rVert^2+\epsilon}.
\end{align}
其中 $q_t$ 来自 conjunctive address，$v_t$ 来自预测后才揭示的 observation。$M_0=0$，episode 结束后丢弃；它不是跨训练持久参数，也不是按 index 读写的 slot bank。covariance correction 用于减少相关地址的串扰。

\subsection{2D-R3 地址审计的首个负结果}

在冻结 PFC/EC features、统一 128D key 与统一 plain-delta memory 的三种子 pilot
中，place-only、additive、concatenation、learned MLP 与 multiplicative 的
correct-context log-$K$ AUC 均为 0.005--0.013；所有 contextual forms 共同失败。
same-place/cross-context key cosine 仍约 0.96，说明去掉 context covariance 后
substrate 已不健康。该结果不能否定 outer product；它触发了共享
context-covariance dual-write 的 stage gate，而不是直接进入正式地址结论。

修复一次 signed-denominator 实现错误后，我们从头运行单种子 stage gate。
Multiplicative 的 correct-context $K{=}1$、log-$K$ AUC 与 clean accuracy 分别仅为
0.141、0.091 与 0.419；预注册的 0.70、$+0.15$ 与 0.90 health gates 均未通过，
且训练 loss 曾跳至 477.118。因而状态为 \textbf{STOP}，不扩三种子，也不在该
代理任务上继续调 ridge 或维度。下一次地址结论必须来自保留完整因子结构的
full-model intervention。

\section{结论}

\model{} 当前不是一个 ``所有 rollout 都赢'' 的完成品，而是一条已有清晰核心与
边界的研究线。2D 结果说明：当 Transformer/PFC 必须从历史推断 context 时，
context-dependent address 与 episode-local HPC 能恢复普通窗口模型、\base{}
和单映射 delta memory 无法恢复的旧内容；R2 进一步排除了时间与局部线索 shortcut。
本轮最关键的新结果是，同一个 causal pattern 已在最小 DINO visual A-B-A 中
跨三个训练 seed 复现，且 wrong-history 会定向调用错误 context 内容。与此同时，
generic RGB rollout 仍只有小幅趋势，caller 泛化仍失败。最有价值的下一步不是
继续堆 gate，而是把 visual pilot 冻结为多 place、shape/category、fresh held-out
的 5--8 seed formal，并完成 full-model 地址与公平预算审计。
